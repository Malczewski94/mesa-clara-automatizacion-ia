# Versiones pendientes de despliegue

`02_envio_hilos.blueprint.json` contiene el ajuste de respuestas en hilo preparado a partir de una exportación real de Make y un módulo Reply to an email configurado en el editor. No sustituye al blueprint principal verificado.

Pendiente: importar en Make, guardar, probar correo nuevo y respuesta conservando el Thread ID, comprobar persistencia, rechazo, versión obsoleta y ausencia de reenvío. Después se debe exportar la versión guardada y actualizar el archivo principal y las evidencias.

Los metadatos de interfaz y las etiquetas de conexiones se redujeron para evitar publicar el correo de la cuenta. Los identificadores de conexión se deben reasignar al importar en otra cuenta. No contiene API keys.
